# NessRC 真实样本特征

## 样本与证据上限

样本来自 `tools/trace_output/cache/` 的 12 张商品缩略图，均为 209–600 px 级 JPEG；尺寸来自 `lib/tracks.ts` 商品名。它们足以判断对象层级和拓扑语言，不足以反推出毫米级曲率、真实宽度、出血或刀线。仓库中未发现高清平面设计源、生产矢量或供应商规范。

## 统计结论

- 12/12 是矩形成品画布/底材，不是透明背景上的孤立道路条带。
- 11/12 有可辨的赛道设计；track-60 是无路线的沥青底材。
- 在 11 个有设计样本中，11/11 都包含独立边界/内岛或开放边界；没有一个能由“唯一单中心线 + 对称等宽 offset”忠实表达。
- 11/11 使用局部开放 curb 与标线；curb 不是“小半径弯自动出现”的副作用。
- 至少 8/11 有停车/pit/起终点等非道路条带对象。
- 至少 track-3/15/25/50/90 五个具有交汇、合流、figure-8 或多可选环路；“检测到中心线自交即拒绝”会误伤真实设计语言。
- 多数样本有沥青纹理、轮胎印、草地/水泥/runoff、Logo 与方向信息；几何合法性与视觉主题必须分层。

## 反推的 V2 必备语义

1. `surfaceRegions`：外圈、洞/内岛、runoff/草地等可组合区域，支持 union/difference 与 fill rule。
2. `boundaryPaths`：可闭合也可开放的几何边界；允许共享/吸附端点。
3. `curbRuns`：沿任意边界区间布置，带 side、宽度、节奏和色组。
4. `markings` / `symbols`：线、停车位、起点线、箭头、文字、Logo 的实例层。
5. `driveGraph`：可选的参考驾驶节点/边/route；junction 和合法交汇显式建模，不决定铺装区域真相。
6. `theme`：纹理、色板、材质与视觉效果；不参与生产边界拓扑。

## 仍缺的样本证据

- 每类至少 5 张高清俯视源，尤其是 track-3/15/25/50/90/100。
- 生产刀线/出血文件、尺寸标定点和实际打印成品对照。
- 是否存在桥梁/立体交叉；缩略图只能证明平面视觉交汇，不能证明高程。
- 最小特征、允许的开放 curb 端帽、Logo 安全区、颜色和材料差异规范。
