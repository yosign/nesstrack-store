# 全球漂移竞赛赛道图鉴：研究与生产计划

## 1. 目标与完成定义

制作 50 个全球漂移赛事实际竞赛路线的统一视觉图鉴，每个条目交付一份可编辑 SVG、一份 1600×1200 PNG、完整元数据和可追溯证据。图鉴对象是“某赛事、某年份、某场地采用的漂移竞赛路线”，不是场地的整条公路赛/赛车场布局。

完成必须同时满足：50 个条目地域配额准确；每条路线有足以确认竞赛区间和行驶方向的证据；SVG/PNG 通过视觉与技术 QA；来源、判断和不确定性可审计；所有图均为版权安全的原创重绘。

本计划只定义研究与生产流程，不开展具体赛道研究，不生成图片。

## 2. 收录与排除标准

### 必须收录条件

候选条目必须同时满足：

1. 发生过有组织、有评判规则并公开记录的四轮汽车漂移竞赛；表演、练习日和纯业余聚会不算。
2. 能确认赛事名、年份、场地、城市/国家；同一场地不同年份只有在比赛路线实质变化时才可分别收录。
3. 至少有一项“路线级强证据”，或两项相互独立的“路线级中等证据”，可确认起点、终点、行驶方向及主要弯序。
4. 路线能被清晰重绘为单向竞赛区间；必要的减速区可标注，但不得凭空推断不可见部分。
5. 能够按本计划的版权安全政策进行原创重绘，并在元数据中记录证据与不确定性。

### 优先选择原则

- 世界级、洲际、成熟国家级赛事与历史代表性场次兼顾。
- 永久赛车场、街道/停车场临时场地、山道/特殊场地兼顾。
- 同一赛事系列不被少数国家或少数赛车场垄断。
- 优先有官方路线图、规则/车手简报、可靠比赛录像和可核验卫星/场地图的条目。
- 视觉形态相近时，优先证据更强、地域更稀缺、赛事影响更大的候选。

### 明确排除

- 仅有赛道全图，无法确认漂移比赛实际使用区间、方向或起终点。
- 游戏、模拟器、概念赛道、无真实比赛记录的练习路线。
- 只发生烧胎、甩尾表演、Gymkhana、time attack、rallycross 或 tandem 练习的路线。
- 证据只来自无出处的 Pinterest、社媒转贴、论坛手绘图或 AI 生成图。
- 无法区分年份/布局版本，或不同来源明显冲突且无法消解。
- 需要临摹受版权保护插画的独特视觉表达才能完成的条目。
- 为凑配额而纳入与已选路线在场地、年份和布局上实质重复的条目。

## 3. 50 图覆盖配额

地域以比赛举办地而非赛事总部或车手国籍计。下表为硬配额，总计 50；任何替换必须留在同一地域配额内，除非由项目负责人批准并在审计中说明。

| 地域 | 数量 | 目标赛事/场景覆盖（研究方向，不是预定入选名单） |
|---|---:|---|
| 日本 | 10 | D1 顶级/次级、Formula Drift Japan、历史性专业赛事；至少 4 个不同场地 |
| 北美 | 10 | 美国/加拿大/墨西哥的顶级与国家级系列；至少 3 个国家、2 个临时场地 |
| 欧洲 | 12 | 洲际系列与国家级赛事；至少 8 个国家，东/西/北/南欧均有代表 |
| 大洋洲 | 5 | 澳大利亚、新西兰；两国均覆盖，至少 1 个街道或临时场地 |
| 亚洲（日本以外） | 6 | 东亚、东南亚、南亚；至少 4 个国家/地区 |
| 拉丁美洲（墨西哥除外） | 4 | 南美与中美洲；至少 3 个国家 |
| 中东与非洲 | 3 | 两个大区均须出现；至少 2 个国家 |
| **合计** | **50** | |

赛事层级也设硬配额，并与地域配额交叉核对：国际/洲际顶级系列 28，成熟国家级系列 16，具有正式竞赛规则的历史性或独立邀请赛 6，合计 50。单一赛事系列最多 10 图；单一国家最多 10 图（日本作为独立地域上限亦为 10）；单一场地最多 2 图，且第二图必须有可证实的实质布局变化。

全体 50 图还应满足：至少 10 个临时/街道/停车场路线，至少 30 个不同场地，至少 20 个国家/地区；这些是组合约束，不额外增加数量。

## 4. 候选池、评分与备选机制

### 候选池

先按地域建立不少于 75 个候选，建议每个地域为最终配额的 1.5 倍并向上取整。候选不能仅凭知名度入池，必须先具备赛事、年份、场地的基础身份记录。

### 两阶段筛选

1. **资格门槛**：逐项执行收录/排除标准；没有路线级证据的候选不得进入评分。
2. **100 分评分**：证据完整度 35，路线辨识度 20，赛事代表性 15，地域/场景稀缺性 15，视觉形态多样性 10，版权与重绘风险 5。低于 70 分不进入正式或备选名单；证据完整度低于 25 分直接淘汰。

各地域按分数与组合约束选出 50 个正式条目，再保留至少 15 个有完整证据的有序备选。备选记录 `replacement_for`（可替换的正式条目/地域/层级）、替换原因与重新校验项。生产中若发现路线无法验证、版权风险或严重重复，先使用同地域、同层级、最接近场景类型的最高顺位备选；替换后重新跑全部配额与多样性审计，禁止用低证据候选补位。

在首批 10 图完成 QA 后设置一次样式与证据门槛校准；之后冻结视觉模板。冻结后若修改规范，必须回溯重检已完成条目。

## 5. 来源证据体系

### 来源可靠性层级

- **S 级（官方一手）**：赛事规则/车手简报、官方路线图、官方航拍或完整比赛转播、主办方/赛道发布的明确当年资料。
- **A 级（可靠一手/专业记录）**：车手完整 onboard、专业摄影或媒体的连续航拍/固定机位录像、赛事技术供应商资料、场地方当年资料。
- **B 级（可交叉验证二手）**：信誉媒体报道、摄影集、赛事结果页附图、可定位且时间明确的观众连续录像。
- **C 级（线索）**：社媒单图、论坛、无来源重绘、聚合网站、游戏模组。只能发现候选，不能单独支持入选或几何判断。

每个正式条目至少需要：一项 S/A 级路线级证据，或两项相互独立的 A/B 级路线级证据；另需一项场地底图证据用于定位。来源必须保存页面标题、发布者、URL、发布日期（如有）、访问日、适用赛事/年份、支持的具体判断以及必要的时间码/页码。网页失效时保留合规的文字摘录、截图哈希或 Internet Archive 链接；不得把受版权保护的原图提交为成品资产。

### 场地全图与实际漂移路线的区分

证据表必须把两个问题分开回答：

1. **场地几何证据**：完整赛车场/道路的弯序、相对位置与边界，只能证明“道路存在”。
2. **竞赛路线证据**：当年赛事具体起点、加速区、initiating point、outer zones/clipping points、终点、减速区及行驶方向，证明“比赛实际用了哪一段”。

赛车场官网总图、OpenStreetMap 或卫星图不能单独证明竞赛路线。有效竞赛路线证据应至少连续显示起点到终点，或以官方路线图/车手简报明确标注。若录像只显示局部，必须用另一独立来源补齐。仅靠烟迹、观众位置、护栏或常识推测的区间标记为 `inferred`，核心拓扑含推断时不得进入正式 50 图。

若同一永久赛道存在正向/反向、内外线或不同起点版本，条目 ID 必须绑定年份和赛事；不得以“常用布局”替代当年布局。

## 6. 版权安全的原创重绘政策

- 只提取不可版权化的事实：道路拓扑、相对转角、比赛区间、方向与经核验的竞赛标记位置；成品使用本项目统一视觉语言重新表达。
- 禁止直接描摹、矢量化或自动追踪官方/商业地图的线条；不得复制其配色、图标、字体、纹理、标注排版、比例装饰或独特简化方式。
- 几何应以至少两类来源综合重建，例如官方竞赛信息 + 卫星/开放地图 + 录像；单一专有插画只能作为事实核对，不能成为绘制底稿。
- 优先使用开放许可地图数据，并在元数据记录许可与署名要求；若使用 OSM 派生几何，必须遵守 ODbL attribution，不把其瓦片截图嵌入成品。
- 不使用赛事、系列、赛道、车队或赞助商 Logo；专有名称仅作为事实性文本元数据。成品图内默认只显示中性序号/方向符号，不复刻官方标识。
- 每条记录填写 `redraw_basis`、`source_licenses`、`derivative_risk` 和复核人。无法把事实与原作表达分离时改用备选。

## 7. 每条赛道的元数据

主清单每行/每对象至少包含：

- 身份：`track_id`、`display_name`、`event_name`、`series`、`event_tier`、`event_year`、`round`。
- 地理：`venue_name`、`city`、`country_or_region`、`iso_country_code`、`atlas_region`、经纬度（场地中心点）。
- 路线：`venue_type`（permanent/street/parking/mountain/other）、`course_variant`、`direction`、`start_description`、`finish_description`、`initiation_description`、`judged_features`、`course_length_m`（仅有可靠值时）、`geometry_basis`、`inference_notes`。
- 证据：`sources[]`（`source_id`、tier、title、publisher、URL、published_at、accessed_at、page_or_timecode、claim_supported、license）、`evidence_status`、`evidence_conflicts`。
- 选择：`selection_score`、`quota_region`、`event_tier`、`diversity_tags`、`backup_rank`、`replacement_for`。
- 生产：`artist`、`researcher`、`reviewer`、`redraw_basis`、`source_licenses`、`derivative_risk`、`svg_sha256`、`png_sha256`、`status`、`qa_date`、`version`。

缺失值统一为 `null`，不得用估算值冒充事实；可估算的值另以 `estimated_*` 字段保存并注明方法。

```text
public/images/global-drift-track-atlas/

```

`track_id` 格式固定为：

```text
<iso2>-<city-slug>-<venue-slug>-<series-slug>-<yyyy>
```

只用小写 ASCII、数字与连字符；城市/场地/系列使用简短英文 slug；不含空格、下划线、重音符号或版本词。例：`us-long-beach-shoreline-fd-2025`（仅示范格式，不代表入选）。同年同场地确有两条不同比赛路线时追加 `-a`、`-b`，并在元数据说明差异。SVG、PNG 与条目 Markdown 必须同名；更新内容不改文件名，以元数据 `version` 管理。

## 9. 1600×1200 SVG / PNG 视觉规范

### 画布与布局

- SVG 根元素固定 `width="1600" height="1200" viewBox="0 0 1600 1200"`；PNG 精确为 1600×1200 px、sRGB、8-bit RGBA。
- 背景透明；安全区为四边 96 px。路线主体在安全区内尽量放大，较长边占可用区域 78%–88%，不旋转到违背地图北向；若为版面适配而旋转，显示 North arrow 并记录角度。
- 全系列以地图北向朝上为默认。无法可靠定位北向时，使用“行驶方向优先”的自然横向布局并在元数据标记 `orientation_basis: course`。
- 图内不放标题、赛事 Logo、赞助商或来源水印；命名与说明由页面 UI/元数据承载。

### 图层与样式

SVG 分组 ID 固定为 `background`、`context`、`course`、`zones`、`markers`、`labels`。未使用的组仍可保留为空，便于自动校验。

- 非竞赛场地上下文：中性灰 `#CBD2D9`，16 px，圆头圆角，40% 不透明度；只画理解路线所需的最少部分。
- 实际竞赛路线底层：深色 `#111827`，52 px，圆头圆角。
- 路线中心强调线：白色 `#F8FAFC`，4 px，60% 不透明度。
- 行驶方向：`#22C55E`，三角箭头；每图 1–3 个，不能遮挡关键弯。
- 起点/终点：起点 `#22C55E`、终点 `#EF4444`，各 18 px 圆点并配 `S`/`F`；文字使用项目批准的开源无衬线字体，转换为 path 或保证 Web 安全回退。
- 评判区/clip（仅有证据时）：inner `#F59E0B`、outer `#A855F7`；不得根据常见漂移规则自行补画。不同年份规则不明确时完全省略。
- 不使用渐变、阴影、照片纹理或模拟官方地图的装饰。线宽、箭头、标记缩放后保持全系列一致。

### 几何处理

- 重绘保留拓扑、主要转向与相对直/弯比例，但允许为 1600×1200 可读性进行一致的轻微简化；禁止把急弯改成不同弯序。
- 所有开放路径必须从起点连续到终点，不得隐藏断点、自交或多余分支。上下桥仅在证据确认时使用标准断桥符号。
- SVG 仅包含本地向量元素，不含外链、脚本、base64 图片、`foreignObject` 或嵌入字体文件。
- PNG 从最终 SVG 以确定性脚本导出，不单独手工修图；SVG 与 PNG 视觉内容必须一致。

## 10. 单条生产流程

1. 建立候选身份记录并通过资格门槛。
2. 收集与登记来源，分别完成场地几何证据和竞赛路线证据表。
3. 由研究员绘制低保真路线草图，标出每个判断对应的来源/时间码；冲突先解决，不把不确定性推给制图员。
4. 第二名研究员盲核起终点、方向、弯序和年份版本；通过后状态改为 `evidence-approved`。
5. 制图员按冻结模板原创重绘 SVG；自动导出 PNG，生成哈希。
6. 技术 QA、视觉 QA、版权/证据 QA 分别由非制图者签字；失败则退回对应步骤。
7. 更新 manifest 和条目 Markdown；批次状态只在所有检查通过后改为 `complete`。

建议按 10 图一批生产。第一批用于校准，后四批按相同模板执行；每批完成后即时做配额和重复性审计，不把问题留到第 50 图。

## 11. QA 清单

### 证据与内容

- [ ] 赛事、年份、场地、国家和系列身份一致，无版本混用。
- [ ] 有合格的路线级证据，且起点、终点、方向、主要弯序逐项可追溯。
- [ ] 已明确区分场地全图和竞赛路线；无核心拓扑推断。
- [ ] clip/zones 只在对应年份证据明确时出现。
- [ ] 来源 tier、URL、访问日、页码/时间码、许可和支持主张填写完整。
- [ ] 与同场地/同系列其他条目比较，确认不是实质重复。

### 视觉与几何

- [ ] 画布、安全区、占比、方向和 North arrow 符合规范。
- [ ] 路线连续，弯序、方向、起终点与证据一致；无意外断点、自交或分支。
- [ ] 固定色值、线宽、圆角、箭头、标记、图层 ID 一致。
- [ ] 无 Logo、赞助商、受保护插画风格、照片或多余文本。
- [ ] 缩略到 400×300 仍能识别路线和行驶方向；放大 400% 无锯齿/路径异常。

### 技术与文件

- [ ] SVG 为 1600×1200 / `viewBox 0 0 1600 1200`，无外链、脚本、嵌图、`foreignObject`。
- [ ] PNG 精确 1600×1200、sRGB、8-bit RGBA，透明背景正确。
- [ ] SVG/PNG/Markdown 文件名与 manifest 中 `track_id` 完全一致。
- [ ] PNG 由当前 SVG 自动导出，视觉像素对比无缺层、错色或裁切。
- [ ] SVG 和 PNG SHA-256 已写入 manifest，自动验证脚本返回零错误。
- [ ] 元数据必填字段齐全，JSON schema 与 CSV 行数通过校验。

### 版权与人工签核

- [ ] `redraw_basis` 说明了多源重建过程，无直接描摹/追踪。
- [ ] 开放数据署名与许可要求已满足；无不允许再分发的源资产进入仓库。
- [ ] 研究员、制图员、复核员均记录，复核员不是该图制图者。

## 12. 最终完成审计

交付前由未参与日常制图的负责人执行一次全量审计，并在 `completion-audit.md` 记录机器输出、人工抽检和例外：

1. 文件计数必须恰为 50 SVG、50 PNG、50 条 track Markdown、manifest 50 个正式记录；不得把备选算入。
2. 地域配额为 `10/10/12/5/6/4/3`，赛事层级为 `28/16/6`；国家、场地、临时路线和单系列/单国/单场地上限全部通过。
3. 所有 50 条执行 schema、命名、尺寸、颜色、图层、外链/脚本、哈希和 SVG→PNG 一致性自动检查。
4. 对 50 条逐一核对证据门槛；随机抽 20%，由独立复核员从原始来源重新确认弯序、方向和起终点。
5. 使用感知哈希/轮廓相似度找出潜在重复，再人工判断；任何未解释的高相似对都阻止发布。
6. 以 5×10 contact sheet 检查全系列尺度、线宽、朝向、留白、色彩和标记一致性，并在 400×300 缩略图尺寸复核可读性。
7. 完成版权台账，确认仓库无来源原图、视频帧、商业地图截图、Logo 或被追踪矢量；所有开放数据 attribution 可从条目追溯。
